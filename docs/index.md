# DocPilot restic documentation

These topics document restic, an open-source backup program. They are a sample of a docs-as-code workflow: every topic has a type, a template and automated checks.

## Where to start

- To learn the ideas first, read [Repositories and snapshots](concepts/repositories-and-snapshots.md).
- To try restic now, follow [Install restic](tasks/install-restic.md).
- To look up a command, see the [Command reference](reference/restic-commands.md).

## How this site is organized

Each topic is one of three types:

| Type | Purpose |
|---|---|
| Concept | Explains what something is and why it works that way. |
| Task | Gives numbered steps to reach one goal. |
| Reference | Lists facts to look up, such as commands and flags. |
